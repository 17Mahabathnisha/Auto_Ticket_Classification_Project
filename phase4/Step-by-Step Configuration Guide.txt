# Phase 4: Step-by-Step Configuration Guide

## ⚙️ Step-by-Step Configuration Guide

### Step 1: Open System Dictionary for Subcategory
1. Navigate to an Incident Workflow form (`u_incident_workflow`)[cite: 5].
2. Right-click the **Subcategory** field label[cite: 5].
3. Select **Configure Dictionary** from the context menu[cite: 5].

---

### Step 2: Enable Dependent Field in Advanced View
1. On the Dictionary Entry form, click the **Advanced view** related link[cite: 5].
2. Navigate to the **Dependent Field** tab[cite: 5].
3. Check **Use dependent field** = `true`[cite: 5].
4. In the **Dependent on field** selector, select `Category` (`u_category`)[cite: 5].
5. Click **Update** or **Save**[cite: 5].

---

### Step 3: Map Choice Dependent Values in `sys_choice`
1. Scroll down to the **Choices** related list on the Dictionary Entry form[cite: 5].
2. Edit each choice record to populate the **Dependent value** column[cite: 5]:
   - For `Wi-Fi` → Set `Dependent value` = `network`[cite: 5]
   - For `Projector` → Set `Dependent value` = `hardware`[cite: 5]
   - For `Forgot Password` → Set `Dependent value` = `access`[cite: 5]
   - For `Slow Computer` → Set `Dependent value` = `performance`[cite: 5]
3. Save all updated choice records[cite: 5].
