--------------------------------------------------
📌 PHASE OVERVIEW
--------------------------------------------------
The objective of Phase 3 is to design an intuitive, responsive 2-column intake form using ServiceNow's visual Form Designer, and populate the table data schema with appropriate field data types, reference links, and choice list values.

--------------------------------------------------
🎯 KEY OBJECTIVES
--------------------------------------------------
1. Design a 2-column layout for the `Incident WorkFlow` ticket intake form.
2. Add relational reference fields linking to `sys_user` (Caller, Assigned to) and `sys_user_group` (Assigned Group).
3. Configure the primary Category choice options (`network`, `hardware`, `access`, `performance`).
4. Set up Subcategory choices and lifecycle State values.
